# AI Study Mentor X 🎓

AI Study Mentor X is an interactive, AI-powered study assistant built with Streamlit and the Google Gemini API. It helps students learn faster, remember longer, and score higher.

## Key Features
- **PDF Upload**: Upload course notes and extract text.
- **AI Summary**: Get instant summaries including key concepts, important topics, and exam tips.
- **AI Tutor**: Interactive Q&A chat based on the uploaded notes.
- **Quiz Generator**: Generate 10 MCQs with answers, grade answers, and track scores.
- **Weak Topics**: Identify concepts that need more study based on quiz performance.
- **Study Planner**: Receive a customized, day-by-day plan leading up to your exam.
- **Analytics Dashboard**: Check metrics, average scores, and score trends with Plotly charts.

## Setup & Running
1. Clone or download this project.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Streamlit application:
   ```bash
   streamlit run app.py
   ```
